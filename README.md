# Kettlebell Forge

A kettlebell workout timer that runs in the browser and installs to your phone's home screen.

- Full-body kettlebell complexes, bodyweight moves and your own custom workouts
- Illustrated exercises with coaching cues
- Spoken "up next" cues and a 3-2-1 countdown between moves
- Workout log with the weight you used per exercise, shown again next time
- Works offline once opened

## Install on your phone

Open the site, then:

- **iPhone (Safari):** tap Share, then **Add to Home Screen**
- **Android (Chrome):** tap the ⋮ menu, then **Add to Home screen** or **Install app**

Your workouts and history are saved on the phone. Use **Log → Backup** to copy them to another device.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole app |
| `manifest.webmanifest` | Name, colours and icons for the home-screen app |
| `sw.js` | Offline support. Bump `VERSION` when `index.html` changes |
| `icons/` | App icons |
